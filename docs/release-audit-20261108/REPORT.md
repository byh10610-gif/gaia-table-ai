# 가이아 프로젝트 배포 전 종족 규칙 감사

**판정: 확인된 규칙 오류 5건을 수정하기 전 최종 배포 보류 권장.**

- 검사 기준: GitHub `byh10610-gif/gaia-table-ai`, main `411967adbfabdb1508edc7bb023e89ea23d9caa5`
- 검사일: 2026-11-08 (한국 시간)
- 기존 테스트 6개 모두 통과.
- 종족 규칙 검사 **172개 중 166개 통과, 6개 실패**. 실패 6개는 원인 기준 5건.
- 18종족 각각을 주 플레이어로 한 3인 자동 게임: 쉬움 18회·보통 18회, **36/36게임 6라운드 종료**, 총 3,428행동.
- 앱 실행 파일은 변경하지 않음. 이 브랜치는 재현 테스트와 감사 결과만 추가하며 main/Pages에는 반영하지 않음.

### 원인과 재현

**F01 — apply_action / applyBuildMine**

`lostFleet && playerCount===3` 분기가 원래 지식 2 보상을 대체하여 chargePower(1)만 실행합니다. 확장 규칙서 p8 조정 타일에는 지식2와 파워1이 함께 있습니다. 의회가 있는 란티다로 사거리 안 상대 광산에 공동 개척하면 재현됩니다.

**F02 — income / factionIncomeConfig, listIncomeSources**

란티다 전용 planetaryInstitute 수입 override가 없어서 기본 의회의 토큰1을 가져옵니다. 동시에 `lantids_lost_fleet_adjustment`가 토큰1을 더합니다. 공식 종족 요약 p16의 란티다 의회는 4충전이고, 확장 기본 토큰 수입은 의회와 독립된 별도 효과입니다.

**F03 — passive_charge / listPassiveChargeOffers, currentPassiveChargeOffer, resolvePassiveChargeChoice**

- 의회 보유, 일반 토큰 모두Ⅲ: 새 토큰을 먼저 받아 충전할 수 있는데 제안이 없습니다.
- 의회 보유, Ⅰ=0·Ⅱ=1·Ⅲ=5: 새 토큰을 먼저 받으면 3충전/승점2 지불이 가능하지만 상한1에 막혀 1충전만 합니다.
- UI 충전 수락도 선/후 순서 선택을 노출하지 않고 기본 after로 처리합니다. 제안·미리보기·실행·AI의 계산을 함께 수정해야 합니다.

**F04 — legal_actions / listFactionSpecialActions, apply_action / applyFactionSpecialAction**

파이락 다운그레이드에 다른 라운드1회 특수행동과 동일한 사용 플래그를 적용합니다. 의회와 연구소2개·교역소재고2개 이상을 두고 연구소1개를 전환하면, 다른 연구소 전환 후보가 사라집니다. 기본 규칙서 p21에는 이 행동에 라운드1회 제한이 없습니다. 앰바스·매드 안드로이드 등의 진짜 라운드1회 제한과 구분해야 합니다.

**F05 — income / factionIncomeConfig**

스페이스 자이언트 전용 의회 수입 override가 없어 기본4충전을 받습니다. 공식 확장 규칙서 p16 종족 요약은6충전입니다.

## 재실행 방법

설치 패키지 없이 Node.js로 실행합니다.

```sh
node tests/faction-rules.cjs
node tests/faction-simulation.cjs terrans 41
node tests/faction-simulation.cjs terrans 83 normal
```

- 첫 명령은 기준 버전에서 발견 오류를 드러내기 위해 **의도적으로 종료 코드1**을 반환합니다. 잘못된 현재 동작을 정답으로 고정하지 않았습니다.
- 검사 결과 JSON 기본 위치는 OS 임시 폴더의 `gaia-release-audit-results`입니다. `GAIA_AUDIT_OUTPUT` 환경 변수로 변경할 수 있습니다.
- 시뮬레이션은 실제 createPlayableGame 확장 지도와 현재 AI를 사용합니다. 특정 종족을 첫 플레이어로 놓고, 구성물 색이 겹치지 않는 다른2종족을 함께 배치합니다.
- 쉬움 seed41, 보통 seed83. 엔진 VM의 Math.random에 재현 가능한 난수열을 사용합니다.
- 36게임 상세 결과: [simulation-results.json](simulation-results.json)
- 172개 검사 상세 결과: [faction-rules-results.json](faction-rules-results.json)

## 확인 범위와 한계

- 36게임 완주는 교착/예외 검증이며, 규칙이 모두 맞거나 AI가 숙련자 수준이라는 뜻은 아닙니다.
- 2/3/4인 시작 세팅은 모두 검사했지만, 6라운드 자동 게임은3인 위주입니다. 모든 종족 조합·모든 난이도·모든 타일 조합을 전수검사하지 않았습니다.
- 의회 수입은 공식 종족 요약 그림과 별도로 대조했지만, 모든 시작 자원과 모든 건물 열의 숫자를 실물 종족판 고해상도 사진으로 독립 대조한 것은 아닙니다.
- 실제 사용자 저장 JSON, iPhone/iPad Safari 터치·파일 불러오기, 실제 실물 보드 대조 플레이는 이번에 수행하지 않았습니다.
- 실제 Google Analytics 수신은 이번 검사 대상이 아닙니다.
- 이번 감사에서는 앱 코드 수정·main 병합·새 배포를 하지 않았습니다.
